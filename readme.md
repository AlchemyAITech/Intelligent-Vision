# 智能视界 (Intelligent Vision) — AI 互动教学与实验平台

## 项目简介

**智能视界 (Intelligent Vision)** 是清华大学 2026 通识课程的核心配套实验平台。不同于传统的幻灯片教学，本系统采用纯前端 **Vue 3** 驱动界面，结合 **FastAPI + PyTorch** 构建强大的高性能推理后端，为学生提供“开箱即用、所见即所得”的互动式计算机视觉学习体验。

平台将深度学习黑盒“透明化”，涵盖从基础像素操作、卷积核滤镜，到神经网络训练的“全链路观测”，再到 YOLO 检测、SAM 3 万物分割以及实时人脸识别等前沿技术的亲身实践。

## 🚀 快速开始

### （1）安装环境

建议使用 Python 3.10+ 环境。为了避免依赖冲突，推荐使用虚拟环境：

```bash
# 1. 创建虚拟环境 (在项目根目录下)
python -m venv .venv
# 如果不成功尝试
python3 -m venv .venv

# 2. 激活虚拟环境
# Mac / Linux:
source .venv/bin/activate
# Windows (Command Prompt):
# .venv\Scripts\activate.bat
# Windows (PowerShell):
# .venv\Scripts\Activate.ps1

# 3. 安装核心依赖包
pip install -r requirements.txt

```

### （2）一键运行

项目内置了一键启动脚本，自动处理环境依赖并为您唤起后台 FastAPI 引擎和前端挂载服务：

```bash
# Mac / Linux:
chmod +x start.sh
./start.sh

# Windows (命令提示符):
start.bat

# Windows (PowerShell):
.\start.ps1
```

> **💡 提示**：启动成功后，请在浏览器中访问：**[http://localhost:32100](http://localhost:32100)**

## 🔬 六大核心实验室集群

### 1. 🎨 图像的本质 (Color Lab)

* **色彩空间漫游**: 支持原图在 RGB、HSV、YCbCr、Grayscale 之间的实时转换与解析。
* **微观像素观测**: 特有的“红框扫描”功能，能够提取指定区域 20x20 的像素矩阵，直观揭示图像的数字本质。

### 2. ⚙️ 卷积实验室 (Convolution Lab)

* **实时滤波器**: 内置边缘检测 (Sobel, Prewitt)、图像平滑 (Gaussian, Mean Blur)、锐化等 10+ 种经典卷积核。
* *New!* **⚡ 动态卷积演示**: 提供平方级加速的 **实时扫描动画引擎**，双 Canvas 同步渲染，让学生肉眼观察卷积核游走于输入图像并逐像素计算结果的物理全过程。

### 3. 🤔 神经网络原理 (CNN Lab)

* **网络架构解剖**: 可视化构建 CNN 模型，支持动态下发训练超参 (优化器、损失函数)。
* **状态机托管**: 彻底重构了内部流转逻辑，支持安全中止、一键重训以及跨页面的状态驻留与自动跳转模型测试。

### 4. 👁️ YOLO 视觉实验室 (YOLO Lab)

* **现代全能视觉**: 基于 Ultralytics 与 FastAPI 的异步通信架构。
* **🎞️ 流式视频即时解构**: 现已支持**原生 HTML5 视频拖拽加载与本地缓存视频一键挂载**。前端自带高频抽帧引擎，可将任意普通 MP4 转换成类似于摄像头的实时流，体验丝滑流畅的逐帧目标追踪或姿态骨架解析。
* **三大核心子任务**: Detect (目标检测)、Segment (实例分割)、Pose (姿态估计)。

### 5. ✨ (已移除)

### 6. 👤 人脸实验室 (Face Lab)

* **高精度网格体系**: 基于 MediaPipe 实现单帧 478 点稀疏人脸追踪。
* **身份锚定与追踪**: 接入特征提取网络与重构的 Cosine Distance 识别算法。当检测到身份特征匹配度低于安全阈值时，自动触发视觉级警告光晕。
* **🔐 工业级命名与一致性保障**: SHA256 哈希物理去重，全自动特征特征库更新对齐 (`embeddings_cache.json`) 与静默合并机制。

### 7. 🏭 大模型算法工厂 (Training Platform) *[全新上线]*

* **📦 一站式数据管理面板**: 将零散的图像资料通过简单的拖拽与录入，自动化清洗为 YOLO 训练标准的格式数据集，一键拆分 `train/val/test`。
* **🔥 异构加速训练控制台**: 从前端输入数据增广 (Augment)、超参数 (Epochs, Batch, Seed)，后端守护进程原生透传至 YOLO 训练引擎。
* **📈 实时多维遥测图谱 (ECharts)**: 实现高频轮询与原生 ANSI 色码剥离。伴随着训练过程的推进，界面中 **Box Loss (衰减)** 与 **mAP@50 (精度)** 将自动生成响应式的实时折线动态图，彻底革新“黑盒运行”体验。
* **🔮 Grad-CAM 可解释性探测**: 特征层可视化反演系统。上传任一图像即可实时生成深层卷积特征热力图，透视 AI 判断时的注意焦点。
* **🌐 PCA 高维聚类雷达**: 将抽象的 512 维潜变量特征通过主成分分析法降维投影至二维星空图，直观展现多头分类器的数据边界区隔。

## 🛠️ 技术架构演进 (v2.0+)

本项目已完成了由单体架构向**云原生前后端分离架构**的史诗级重构：

### 1. 视效增强的前端基座 (Frontend)

* **Vue 3 (Composition API)**: 取代了厚重的传统模板渲染，实现状态的超高速响应流转。
* **纯净无依赖栈**: 仅引入 Axios 与 ECharts 进行 API 交互与图表渲染，免于繁琐的 `npm install` 依赖地狱，通过 ESM 原生运行。
* **CSS 模块化系统**: 提炼全局色彩 Token 与毛玻璃 (Glassmorphism) 层级，界面全方位适配暗调与亮彩主题体系。

### 2. 大吞吐量的推理后端 (Backend)

* **FastAPI 引擎**: 基于 ASGI 服务器 `uvicorn` 提供极致并发性能。
* **PyTorch 深度融合**: 构建了常驻内存的模型管理单例 (Singletons)，大幅缩减网络加载耗时。
* **跨平台异构计算**: 深度适配 Apple Silicon (M4 Pro) 及非 CUDA 设备，实施了严格的回退策略与多进程并发安全控制。
